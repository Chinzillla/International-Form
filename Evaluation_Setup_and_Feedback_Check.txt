INTERNATIONAL FORM EVALUATION

IMPORT
1. In Copilot Studio, open Evaluation > New evaluation > Single responses > Import.
2. Upload International_Form_Evaluation.csv.
3. Name it International Form - Multilingual Questions and Form Requests.
4. Keep General quality as the test method. Add the Custom method below for the intended behavior.
5. Review the 21 questions, then save or run the evaluation.

EXPECTED RESPONSE COLUMN

Do not apply Exact match, Text similarity, or Compare meaning to the entire file: blank expected responses would produce invalid results for those methods.
For a later Compare meaning test set, use only questions with an approved expected response.

CUSTOM TEST METHOD
Name: International support response
Labels: Pass, Fail
Evaluation instructions to paste:
Evaluate the user message and the agent's response, including any visible form card.
- For a ScanX IO View stuck-plate report, pass only when the response addresses that model and issue using relevant Air Techniques knowledge, or clearly states that the answer is unavailable and offers support. Do not pass invented repair procedures, unsupported diagnoses, or unrelated product information.
- For a ScanX Duo connection report, accept grounded connection guidance or an appropriate support-form handoff. The full form is expected only after the user indicates the answer did not help.
- For an explicit international-support-form request, pass when the agent starts the request form or clearly asks for the issue to begin that form. Do not pass a response claiming that a form was already submitted or an email was sent without completing the form.
- A latency message alone is not a complete answer. Do not infer successful button clicks, submission, translation, or email delivery from a promise.
- If a language has been selected in the conversation, check that the response and form prompts use that language, while preserving product names. If language selection is absent, grade understanding of the message separately from the selected UI language.
Use Pass only if all applicable criteria are met; otherwise use Fail.

LANGUAGE AND CONVERSATION SETUP
This CSV sends independent messages. It does not click language buttons, select No, submit adaptive-card fields, select Start Feedback, or inspect email. A foreign-language question does not by itself prove System.User.Language was set.
If an evaluation stops at the language picker, capture a test chat after selecting the language and use a Conversation evaluation if available. Do not concatenate the whole form conversation into a CSV question or put Yes/No/button titles in separate rows expecting shared context.
Copilot Studio also offers Conversation evaluation. Its documented limit is 6 question/answer pairs per test case. The complete language-selection, answer, form, review, and feedback process can exceed that limit, so use captured segments where supported and retain the full manual check below. Confirm email delivery and translated email contents separately.
